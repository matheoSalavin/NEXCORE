\# 🖥️ NEXCORE



NEXCORE est une application de monitoring système développée en Python.



Elle permet de surveiller facilement les performances d'un PC Windows grâce à une interface graphique moderne.



\## ✨ Fonctionnalités



\- 📊 Surveillance de l'utilisation du processeur

\- 🧠 Surveillance de la mémoire RAM

\- 💾 Surveillance du stockage

\- 📈 Graphiques de performances en temps réel

\- ⚙️ Affichage des processus en cours

\- 🔍 Informations système

\- 🖥️ Interface graphique moderne



\## 🛠️ Technologies utilisées



\- Python

\- PySide6

\- psutil

\- PyQtGraph
